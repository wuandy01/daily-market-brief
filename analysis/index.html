FOMO研究院電子報09/26

Muse令CPU需求上升？亞馬遜為何封鎖？平台公司怎麼辦？──KP思考筆記(第61期)

文章聚焦Meta於9月初推出的個人AI代理「Muse」，指出每個使用者的運算工作階段其實是跑在AMD EPYC「Turin」CPU主機的獨立沙盒中，而非仰賴GPU；作者以此為核心論點，主張代理型AI在任務調度、工具呼叫與沙盒運算等環節對CPU算力的需求，市場先前明顯低估。

#Meta#Muse#CPU需求#AI Agent

作者指出，這項CPU角度的論述與近期Arm、Intel、AMD等CPU相關個股股價明顯走揚的走勢相呼應，顯示市場正重新評估「AI基礎建設不只是GPU的戰場」；文章同時觀察到亞馬遜AWS似乎對Muse在其雲端平台上的運作採取限制或封鎖態度，並就此提出競爭與服務條款層面的解讀，認為AWS可能有意保護自身的AI代理生態系。

文章最後延伸探討，隨著代理型AI逐漸普及，其他雲端與平台業者在策略上需要因應運算需求結構從「GPU為主」轉向「CPU、GPU並重」的轉變，這也是後續觀察AI基礎建設資本支出配置的重要線索之一。

不預測漲跌09/25

Akamai 接下 Anthropic 116 億美元 CPU 容量長約：資本支出與記憶體貨款先付，2026 年營收指引不變｜算力超週期系列21｜Trend Core

文章解析Akamai與Anthropic剛公布的合作案：Anthropic承諾以約116億美元、為期7年的合約向Akamai承租CPU算力容量，是Akamai公司史上最大合約，消息公布後股價一度大漲逾一成五至二成；作者指出合約採「不用也要付」的take-or-pay架構，讓Akamai取得罕見的營收能見度。

#Akamai#Anthropic#CPU算力#算力超週期

作者特別強調財務時間差：儘管Akamai因這筆合約將2026年資本支出上修約17億美元（其中包含透過Jabil預先鎖定記憶體等零組件的採購授權），但2026年幾乎不會認列任何相關營收，實際營收要到2027年下半年才開始挹注（約1.5至3億美元），並預期到2028年底逐步爬升至約17億美元的年化營收規模，兩年總建置資本支出估計達55億美元。

文章將此案放進其持續追蹤的「算力超週期」系列中，作為說明AI基礎建設「資本支出先行、營收大幅遞延」財務結構的案例研究，提醒讀者評估這類合約價值時，須留意現金流入與流出的時間落差，而非只看合約總金額。

美股送分題09/21

Coverage Universe｜投資假設驗證日誌#3 2026.09｜下季新增兩家Coverage公布

這是作者長期追蹤的季度「投資假設驗證」系列第3篇，目的是檢視自己過去對追蹤名單的投資論點是否真的兌現，而非僅憑本益比高低做買賣判斷；本期以NVDA、MRVL近三個月的表現為例，並提到自訂的「論點成功機率」指標由78%上升至82%。

#NVDA#MRVL#投資紀律#研究方法

文章提出一個值得深思的問題：市場一致預期上修每股盈餘，是否必然等於股價會隨之上漲？作者藉由回顧追蹤名單的實際表現，指出兩者之間並非必然畫上等號，投資人仍須進一步檢視個股評價與市場預期是否已提前反映。

本期同時公布追蹤名單調整：德州儀器（TXN）與亞德諾（ADI）自常態月度追蹤名單中移除，並將於下一季新增兩家公司納入追蹤範圍；整體而言，這個系列強調的是建立可長期驗證、累積證據的研究紀律，而非單純被動因應市場消息做出買賣反應。

財報狗產業報告07/27

玻璃基板製程解析：三大成型工法與台灣供應鏈布局

財報狗產業報告延續先前對玻璃基板的討論，這次聚焦實際製程細節，包括玻璃原料選擇、TGV開孔、金屬鍍層、表面處理到切割檢測等關卡。文章認為無鹼硼鋁矽酸鹽玻璃因熱膨脹係數可調、平整度佳，是目前最可能成為主流的材料選擇。

#玻璃基板#先進封裝#半導體材料#台灣供應鏈

報告比較三種成型工法：溢流下拉法製程中玻璃不接觸模具、良率與品質最佳；狹縫下拉法適合超薄化應用；浮式法則以低成本、量產效率見長但性能相對較低，三者各有適用情境。

文中提及的潛在供應鏈廠商屬於作者推論性質，並非證實已切入玻璃基板生態系的名單，財報狗提醒讀者仍需自行查證，這也反映玻璃基板作為新興材料，市場資訊仍在逐步明朗化階段。

富果直送07/22

Alphabet（GOOGL）2Q26 法說會解析：雲端成長亮眼、卻現罕見自由現金流轉負

富果直送分析師解析Alphabet第2季法說會重點，雲端事業營收年增82%創佳績，但資本支出guidance再度上修，導致公司出現罕見的自由現金流由正轉負，法說會後股價明顯下跌並牽動大型科技股同步走弱。

#Alphabet#雲端運算#資本支出#自由現金流

文章指出，雲端82%的營收成長率是本次法說會少數亮點，顯示Google Cloud在企業與AI基礎建設需求上仍維持強勁動能，帶動整體營收與每股盈餘同步創高。

然而資本支出guidance連續上修，使公司自由現金流出現近年罕見的由正轉負，市場解讀為AI基建投資壓力持續加大，後續恐須更倚賴舉債或發行股權籌措資金，這也是法說後股價走弱的主要原因。
